# Week 3 — Linux, Automation, Cloud, and Electronics

Week 3 introduced a combination of software systems, automation, cloud concepts, and electronics. The week provided exposure to multiple areas of technology and demonstrated how different tools can work together within a development workflow.

The first part of the week focused on Linux and operating systems. Different Linux distributions were explored, along with the fundamentals of working in a Linux environment. A small project was developed within the environment to reinforce the concepts and provide practical familiarity with the operating system.

The next stage introduced terminal-based development, Docker, and cloud computing. Working with the command line strengthened programming and system interaction skills, while Docker demonstrated how containerization can simplify application deployment. Cloud technologies were also introduced through practical application of the developed project.

Automation became another important component. Tools for automating repetitive tasks were explored with the goal of improving productivity and maintaining consistency. A workflow was created to connect content management with the development process, demonstrating how automation can reduce repetitive manual work and keep project information updated.

The final part of the week shifted toward electronics. Basic electrical and electronic components were introduced through practical experiments and simulations. A multimeter was used to understand electrical measurements and troubleshoot circuits, while hands-on circuit building and soldering provided practical hardware experience.

Week 3 therefore connected several different areas: **Linux, programming, Docker, cloud computing, workflow automation, electronics, measurement, and hardware prototyping**. The combination helped demonstrate how software and hardware knowledge can complement each other in technical projects.
